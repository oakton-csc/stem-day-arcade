Join the Computer Science Club

Here’s what members do, from a first line of code to a game strangers play on STEM Day.

Build

Skip

Build

Make a real game

Members build short games in plain HTML, CSS and JavaScript. You don’t need experience: lots of members build theirs with Claude’s help and learn how every line works.

Ship

Ship it like a dev team

Every game comes in through a GitHub pull request. An automatic check tests it, an officer plays it, and once it’s merged it’s live on this site.

Show

Show it on STEM Day

On Thursday, November 19, visitors play what you made, and you get to tell them how it works.

Join

Become one of the Owls who code

Any Oakton student can join, whether you’ve written code before or not. Scan the code with your phone, or tap the button.

Members: add your game

Build it in plain HTML, CSS and JavaScript and send it in as a pull request. Send it early so an officer can play it and merge it before November 19.

  • Runs in a web browser, with nothing to install
  • No logins and no outside websites
  • Someone new can learn it in about two minutes
  • STEM-themed and right for families and high schoolers
