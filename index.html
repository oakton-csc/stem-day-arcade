How members make a game

Write a game in plain HTML, CSS and JavaScript.

No experience needed: lots of members build theirs with Claude’s help and learn how every line works.

Then send it in as a GitHub pull request.

An automatic check tests it, an officer plays it, and once it’s merged it’s live in this arcade.

Then watch visitors play it on November 19.

Your game shows up in the line-up, and you get to tell people how it works.
